# v0.3.0b4 - Fabman member email mapping fix

This beta fixes email-based Home Assistant user mappings. Fabman's member `q` search can return full-text matches unrelated to the exact email address, so the integration now filters the results and accepts only one exact email match in the integration's Fabman account. Incomplete or ambiguous searches still fail safely. Numeric member IDs continue to work.

## Install or roll back in HACS

Open **HACS → Fabman → ⋮ → Redownload**, enable **Show beta versions**, select **v0.3.0b4**, download and restart Home Assistant.

To roll back, redownload **v0.3.0b3** and restart. To return to stable, disable beta versions and select **v0.2.0**.
