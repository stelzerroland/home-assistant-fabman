# v0.4.0b5 - QR panel dependency fix

This beta includes the opt-in QR direct links from v0.4.0b4 and declares Home
Assistant's `http` integration as a dependency. The shared panel uses it to serve
its static frontend assets. All per-resource direct links remain disabled by
default.

## Install or roll back in HACS

Open **HACS → Fabman → ⋮ → Redownload**, enable **Show beta versions**, select
**v0.4.0b5**, download it and restart Home Assistant. To roll back, select stable
**v0.3.0** and restart.

## Validation

Automated validation checks Python regressions on Home Assistant 2026.10.1 and
2026.10.2, Ruff, hassfest, HACS metadata and the Playwright frontend suite. The
browser tests use simulated Home Assistant responses. Physical Android/iOS
camera-to-app handoff and live Fabman hardware remain installation acceptance
checks.
